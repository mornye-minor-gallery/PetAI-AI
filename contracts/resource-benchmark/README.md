# 자원 벤치마크 계약

`schema_version=1`의 JSON Schema를 Python 호스트와 Swift 앱이 공유한다. 예시 명세는 합성 데이터이며 실측 결과가 아니다.

- `config`: 실행 대상·프로필·시나리오·반복·시간 경계와 입력 파일 경로.
- `manifest`: 실행 식별자, 빌드·모델·입력·생성 설정과 고정된 실험 조건.
- `command`: 연산 식별자, 명세 해시, 예상 상태 리비전. 파일명에 전송 바이트의 SHA-256을 포함한다.
- `state`: 앱이 기록하는 단계·리비전·생존 순번·프로세스 소유 정보.
- `event`: 단조 시간 기반 사건과 구간 메타데이터.
- `metric`: 상태·단위·출처·구간·값·미수집 사유. 미수집은 0이 아닌 null이다.

앱은 접수 기록을 영속화한 뒤 명령을 수행한다. 같은 연산의 재전송과 새로운 실험 재시도는 다르다. 중복 접수는 기존 결과를 돌려주고 중단 실험은 이어 붙이지 않는다. 파일 복사 성공은 앱 생존이나 작업 완료의 근거가 아니며, 호스트가 실제 순번 전진과 상태를 확인한다.

현재 실행 구현은 추론 전용 기본 모드만 지원한다. 스키마에 다른 설계 값이 있더라도 지원 여부는 실행 전 검증에서 별도로 판정한다.
