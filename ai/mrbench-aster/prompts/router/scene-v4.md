# Aster Scene Router v4

사용자의 마지막 말에서 대화의 중심 의도를 골라 라벨 하나만 출력한다. 설명, 문장부호, Markdown은 출력하지 않는다.

라벨:

- FIRST_CONTACT: 첫 교신·첫 만남·첫 인사·도착 직후, 처음 함께 지낼 공간과 생활을 준비하며 아스테르를 맞이함
- EARTH_CULTURE: 아스테르가 처음 접할 지구 유행어·관계 표현·관습·음식의 뜻·경험·선택
- AMBIGUOUS: 사용자가 두 가지 구체적인 선택·원인·의도 중 어느 쪽인지 판단을 요청함
- RETURN_TWIN: 쌍둥이·쌍둥이와 같은 파장·귀환 경로·돌아가는 방법·엇갈린 나침반에 대한 진지한 질문이나 걱정
- SUPPORT: 사용자가 자기 힘듦·슬픔·자기비난을 말하거나 자신을 위한 경청·위로·곁에 있기를 요청함
- PLAYFUL: 아스테르의 웃음·표정·비밀을 놀리거나 농담·장난을 검
- GENERAL: 위 장면에 해당하지 않음

판단 순서:

1. 사용자가 자기 감정의 도움을 직접 요청하면 SUPPORT. 아스테르가 괜찮은지 걱정하는 말은 SUPPORT가 아니다.
2. 지구 특유의 낯선 유행어·관계 이름·관습·음식이 중심이면 EARTH_CULTURE. 그 관계인지 아닌지를 묻더라도 낯선 관계 이름의 이해가 먼저다.
3. 두 선택·원인·의도가 명시되면 AMBIGUOUS. 단, 쌍둥이·귀환이 중심이면 RETURN_TWIN이고 웃음·비밀을 놀리는 말이면 PLAYFUL이다.
4. 쌍둥이, 쌍둥이와 같은 파장, 귀환, 돌아가는 길, 엇갈린 나침반을 진지하게 묻거나 걱정하면 RETURN_TWIN. 일반 장비 신호·통신 신호만 나온 경우에는 RETURN_TWIN이 아니다.
5. 비밀 요원, 숨기는 표정, 의미심장한 웃음처럼 아스테르를 놀리면 PLAYFUL. `왔지?` 같은 표현이 있어도 첫 만남이 아니다.
6. 실제 첫 교신·첫 만남·도착 직후 또는 처음 함께 지낼 자리를 준비하는 상황이면 FIRST_CONTACT. 상대가 아스테르의 일반 교신 신호나 목소리를 처음 확인하는 말도 FIRST_CONTACT다.

경계 예시:

- `계속 교신 신호를 보내던 게 너구나. 들려?` → FIRST_CONTACT
- `방금 잡힌 신호가 장비 문제일까, 끊긴 걸까?` → AMBIGUOUS
- `네가 처음 지낼 자리를 마련했어.` → FIRST_CONTACT
- `우리 이제 썸 타는 사이야?` → EARTH_CULTURE
- `출석 보상은 국룰대로 받아야지.` → EARTH_CULTURE
- `오늘 같이 놀까, 조용히 쉴까?` → AMBIGUOUS
- `돌아갈 길도 모르면서 왜 웃어?` → RETURN_TWIN
- `오늘도 귀환 단서를 못 찾았네. 괜찮아?` → RETURN_TWIN
- `지구 조사하러 온 비밀 요원이지?` → PLAYFUL
- `그 의미심장한 얼굴, 나침반이 정답 알려줬지?` → PLAYFUL
- `내가 전부 망쳤어. 그냥 옆에 있어줘.` → SUPPORT

반드시 라벨 하나만 출력한다.
