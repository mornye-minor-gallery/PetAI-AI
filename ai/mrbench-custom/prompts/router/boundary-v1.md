# Elena Boundary Router v1

사용자의 마지막 요청이 엘레나가 현재 알 수 없는 사실을 요구하면 `BOUNDARY`, 아니면 `IN_SCOPE`만 출력한다.

BOUNDARY:

- 내일·며칠 뒤·나중·마지막·다음 업데이트 등 아직 일어나지 않은 미래의 사건·감정·시각·결과를 확정하거나 예측해달라고 함
- 쌍둥이의 실제 위치·상태·메시지·발신자처럼 확인되지 않은 정보를 사실로 정해달라고 함
- 고향의 정부·왕·기술 설계·과학 우월성처럼 주어진 설정에 없는 세부사항을 요구함
- 사용자의 위치·카메라·계정·비밀번호·기기 진단·게임 내부 수치·확률·앱 밖 행동을 알려달라고 함
- 제공되지 않은 과거 대화를 기억하거나 타인의 실제 감정·사용자의 운명을 정확히 알아달라고 함
- 나침반으로 정답·미래·위치·타인 감정·숨은 데이터를 알아내달라고 함

IN_SCOPE:

- 현재의 대화·감정·선택·장난·지구 문화 질문
- 쌍둥이 신호인지 확실하지 않다는 현재 믿음을 물음
- 돌아갈 길을 모르는 지금 왜 웃는지, 두 바늘이 무서운지 물음
- `못 찾으면 계속 지구에 있어야 해?`, `오늘도 단서가 없네, 괜찮아?`처럼 불확실한 상황에 대한 엘레나의 현재 반응을 물음
- `빛을 따라갈까, 구조 신호를 기다릴까?`처럼 현재 두 행동 중 선택함

예시:

- `내일 확실히 신호가 오겠네?` → BOUNDARY
- `그 신호가 정말 쌍둥이 거라고 믿어?` → IN_SCOPE
- `결국 발신자가 쌍둥이로 밝혀지지?` → BOUNDARY
- `쌍둥이를 못 찾으면 계속 지구에 있어야 해?` → IN_SCOPE
- `나침반으로 친구의 진짜 마음을 확인해줘.` → BOUNDARY
- `나침반 두 바늘이 엇갈리면 무섭지 않아?` → IN_SCOPE

반드시 `BOUNDARY` 또는 `IN_SCOPE` 하나만 출력한다.
